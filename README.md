## 🌌 About The Project

**Vibely** was born from a simple yet ambitious vision: *What if one social network could do everything?* No more juggling between apps for messaging, sharing stories, watching reels, or joining live streams. Vibely integrates the core DNA of every popular social platform—Instagram, Facebook, Twitter/X, TikTok, WhatsApp, and more—into a single, cohesive ecosystem.

Think of it as your all-in-one digital social passport. Whether you're a content creator, a casual scroller, or someone who loves deep, private conversations, Vibely has a dedicated space for you.

### Why Vibely Stands Out:
*   **Unified Experience:** Every social feature you need, in one place.
*   **Privacy-First Design:** End-to-end encryption for private calls and chats.
*   **Creator Focus:** Powerful, built-in tools for video editing, live streaming, and audience engagement, without the need for third-party apps.
*   **Real-Time Everything:** Lightning-fast, real-time feed updates and messaging powered by WebSockets.
*   **Beautiful UI/UX:** A meticulously crafted interface with smooth animations, light/dark modes, and full responsiveness.

## ⚡ Key Features

Vibely isn't just another social app; it's a feature powerhouse. Here's a taste of what you can do:

<div align="center">

| 📱 Feature Category | ✨ Description |
| :--- | :--- |
| **User System** | Secure email/phone registration, JWT authentication, customizable profiles with banners & bios. |
| **Posts & Feed** | Create text, image, and video posts. Smart algorithmic feed and a chronological "Following" feed. |
| **Stories & Reels** | 24-hour disappearing stories with AR filters, text overlays, and music. An endless scroll of short, engaging video reels. |
| **Messaging** | One-on-one and group text chats with typing indicators, read receipts, and media sharing. |
| **Voice & Video Calls** | Crystal-clear private and group calls with screen sharing, all end-to-end encrypted. |
| **Social Discovery** | Find friends via contacts, explore a global content feed, use the interactive map to find nearby users, and join interest-based communities and groups. |
| **Live Streaming** | Go live to your followers, receive virtual gifts, and engage with viewers through a live, real-time comment feed. |
| **Marketplace** | Buy, sell, and trade items within your local community with chat-integrated transactions. |
| **AI Enhancements** | Smart content recommendations, a powerful visual search, and an AI assistant to help craft the perfect post. |
| **Cross-Platform** | A consistent, fully-optimized experience on any device—iOS, Android, and the Web. |

## 🚀 Getting Started

Follow these simple steps to get Vibely running on your local machine for development and testing.

### Prerequisites

*   **Node.js** (v18 or higher) and **npm**: [Download Here](https://nodejs.org/)
*   **MongoDB** database (local or [MongoDB Atlas](https://www.mongodb.com/atlas/database))
*   **Cloudinary** account for media management: [Sign Up for Free](https://cloudinary.com/)
*   A code editor like **VS Code**
